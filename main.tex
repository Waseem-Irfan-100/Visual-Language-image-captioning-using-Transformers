\begin{abstract}
Image captioning requires joint understanding of visual content and linguistic structure to generate descriptive natural language. Conventional architectures rely on Convolutional Neural Networks (CNNs) for visual feature extraction paired with Recurrent Neural Networks (RNNs or LSTMs) for sequential text decoding, which suffer from inductive grid biases and vanishing gradient limitations. In this work, we present an end-to-end Vision-Language architecture based entirely on the Transformer framework. The visual backbone utilizes a pre-trained Vision Transformer (ViT-B/16) that projects $224 \times 224$ input images into 196 non-overlapping spatial patches plus a classification token ($197 \times 768$), capturing global context through 12 self-attention layers. The language generation is handled by a custom six-layer, eight-head pre-LayerNorm Transformer decoder built from scratch, eliminating any recurrent dependencies. A linear projection bridge aligns visual features into the decoder embedding space, while weight-tying between the BERT WordPiece token embeddings (vocabulary: 30,522) and the final projection layer regularizes training. Evaluated on the benchmark Microsoft COCO 2017 dataset (118,287 training images, 5,000 validation images) over 12 epochs, the proposed system demonstrates monotonic convergence, lowering validation perplexity from 43.83 to 9.73. Using beam search decoding ($k=3$), our model achieves competitive scores across seven automated metrics: BLEU-1 = 0.7238, BLEU-2 = 0.5581, BLEU-3 = 0.4221, BLEU-4 = 0.3225, METEOR = 0.4897, ROUGE-L = 0.5551, and CIDEr = 1.0385. The custom decoder exposes cross-attention distributions natively, providing visual explainability through high-resolution spatial heatmaps that ground emitted tokens directly to corresponding image patches.
\end{abstract}

\section{Introduction}
Automated image captioning is a foundational multimodal task bridging computer vision and natural language processing. The objective is to generate semantically accurate, syntactically coherent sentences describing salient visual entities, attributes, and relationships depicted within an arbitrary input photograph. Real-world applications range from digital accessibility assistive technologies for visually impaired individuals to multimodal search, content moderation, and automated media cataloging.

Historically, the dominant formulation followed the encoder-decoder paradigm pioneered by Show and Tell \cite{vinyals2015show}, where a convolutional neural network (CNN), such as VGG or ResNet, extracted a global spatial visual vector, and a Long Short-Term Memory (LSTM) network decoded it into a sequence of words. Subsequent enhancements introduced spatial attention mechanisms \cite{xu2015show} and bottom-up region proposals derived from object detectors \cite{anderson2018bottom}. Despite their empirical success, these hybrid CNN-LSTM pipelines face fundamental bottlenecks: CNN encoders impose rigid local receptive field biases that struggle to capture long-range contextual relationships without deep stacking, while recurrent decoders suffer from sequential execution constraints and gradient degradation over extended sentence lengths.

The emergence of the Transformer architecture \cite{vaswani2017attention} revolutionized sequence modeling through multi-head self-attention, replacing recurrent recurrence with parallelizable self-attention. Subsequently, the Vision Transformer (ViT) \cite{dosovitskiy2020image} extended self-attention directly to visual patches, demonstrating that pure attention mechanisms can outperform convolutional networks when pre-trained at scale.

In this paper, we develop, evaluate, and interpret a pure Transformer Vision-Language image captioning architecture. Our contributions are summarized as follows:
\begin{enumerate}
    \item We implement an all-Transformer vision-language pipeline that replaces CNN feature maps and LSTM decoders with a pre-trained ViT-B/16 visual encoder and a custom six-layer Transformer language decoder built from scratch.
    \item We design a custom pre-LayerNorm (pre-LN) decoder layer that natively returns cross-attention matrices during generation, enabling explainability heatmaps without requiring runtime monkey-patching of deep learning frameworks.
    \item We implement a stable training recipe incorporating BERT WordPiece subword tokenization, token-to-output weight tying, label smoothing regularizer ($\epsilon = 0.1$), cosine learning rate scheduling with linear warmup, and automatic mixed precision (AMP FP16).
    \item We report an extensive evaluation on MS COCO 2017 across seven automated metrics, verifying that beam search ($k=3$) yields a CIDEr score of 1.0385 and BLEU-4 of 0.3225, alongside systematic ablations of beam width and per-epoch caption evolution.
\end{enumerate}

\section{Literature Review}
\subsection{Early CNN-RNN and Attention-Based Foundations}
Early deep learning systems for image captioning treated the problem as an image-to-text translation task. Vinyals et al. \cite{vinyals2015show} utilized CNNs pre-trained on ImageNet to compress images into a single vector fed as the initial hidden state to an LSTM network. While effective, compressing the entire image into a static vector caused bottlenecking, especially for complex scenes with multiple interacting objects. 

To mitigate spatial information loss, Xu et al. \cite{xu2015show} proposed the ``Show, Attend and Tell'' model, introducing soft and hard spatial attention over CNN feature maps. This enabled the decoder to dynamically attend to specific convolutional grid cells at each time step. Anderson et al. \cite{anderson2018bottom} advanced this concept through the ``Up-Down'' (Bottom-Up and Top-Down) attention framework, replacing grid features with bounding box features extracted from a pre-trained Faster R-CNN object detector. While this established a benchmark, relying on pre-trained object detectors introduced significant computational overhead during feature extraction and limited visual representations to pre-defined object classes.

\subsection{Transformers in Vision and Language}
The Transformer architecture introduced by Vaswani et al. \cite{vaswani2017attention} eliminated recurrence entirely, relying entirely on self-attention and cross-attention mechanisms. In vision, Dosovitskiy et al. \cite{dosovitskiy2020image} demonstrated with the Vision Transformer (ViT) that treating non-overlapping $16 \times 16$ image patches as visual tokens yields strong contextual representations without convolutional inductive bias. In multimodal research, frameworks such as VisualBERT \cite{li2019visualbert}, Oscar \cite{li2020oscar}, and Meshed-Memory Transformer ($M^2$) \cite{cornia2020meshed} explored multi-level Transformer architectures for multimodal reasoning.

Our work builds on these foundations by adopting a clean, decoupled two-stage design: a high-capacity frozen ViT-B/16 encoder providing 197 patch tokens, coupled through a linear projection bridge to a custom 6-layer Transformer decoder trained from scratch using BERT subword tokenization.

\section{Methodology}
\subsection{Problem Formulation}
Given an input photograph $I$, the objective is to generate an output natural language description $Y = (y_1, y_2, \dots, y_T)$, where each $y_t \in \mathcal{V}$ denotes a token from a predefined discrete vocabulary $\mathcal{V}$, and $T$ is the total sequence length terminated by an end-of-sequence token $[SEP]$. Under the autoregressive factorization, the conditional joint probability distribution is parameterized as:
\begin{equation}
P(Y \mid I; \theta) = \prod_{t=1}^T P(y_t \mid y_{<t}, I; \theta)
\end{equation}
where $y_{<t} = (y_1, \dots, y_{t-1})$ represents the previously emitted tokens, and $\theta$ denotes the trainable network parameters.

\subsection{Dataset and Preprocessing Pipeline}
We utilize the full Microsoft COCO 2017 Captioning benchmark \cite{lin2014microsoft}. The training split comprises 118,287 images with 591,753 human-annotated captions (averaging 5 independent reference captions per image). The validation set comprises 5,000 images with 25,014 reference captions. 

During training, each image is randomly paired with one of its five reference captions at each epoch to regularize generation and prevent memorization. Input images undergo standard Vision Transformer preprocessing: resizing to $224 \times 224$ pixels, bilinear interpolation, normalization with ImageNet channel statistics ($\mu = [0.485, 0.456, 0.406]$, $\sigma = [0.229, 0.224, 0.225]$), and data augmentation including random horizontal flipping.

\subsection{Subword Tokenization}
Unlike conventional image captioning systems that construct domain-specific vocabularies based on word frequency thresholds (which frequently encounter out-of-vocabulary $[UNK]$ tokens), we employ the pre-trained BERT WordPiece subword tokenizer (\texttt{bert-base-uncased}) \cite{devlin2018bert}. This vocabulary comprises 30,522 subword tokens. The $[CLS]$ token serves as the beginning-of-sequence ($BOS$) prompt, $[SEP]$ marks sequence termination ($EOS$), and $[PAD]$ facilitates batch padding. Target captions are capped at a maximum length of 50 tokens, which empirically covers 99.97\% of the COCO distribution without truncation.

\subsection{Optimization and Training Strategy}
The model is trained using the AdamW optimizer \cite{loshchilov2017decoupled} with decoupled weight decay of 0.01 and momentum parameters $\beta_1 = 0.9, \beta_2 = 0.98$. The learning rate is initialized with a linear warmup over the first 1,000 steps up to a peak value of $\eta_{\text{max}} = 3.0 \times 10^{-4}$, followed by cosine annealing decay down to $\eta_{\text{min}} = 2.5 \times 10^{-6}$ over the remaining training steps. 

To prevent overconfident predictions and mitigate label overfitting, we utilize Cross-Entropy loss with Label Smoothing ($\epsilon = 0.1$):
\begin{equation}
\mathcal{L}_{\text{LS}}(\theta) = -\sum_{t=1}^T \sum_{k=1}^{|\mathcal{V}|} q_k(t) \log P(y_t = k \mid y_{<t}, I; \theta)
\end{equation}
where the smoothed target distribution $q_k(t)$ is defined as:
\begin{equation}
q_k(t) = (1 - \epsilon) \cdot \mathbb{I}(y_t^* = k) + \frac{\epsilon}{|\mathcal{V}|}
\end{equation}
Training is executed with a batch size of 64 on an NVIDIA Tesla T4 GPU (16 GB VRAM) utilizing PyTorch Automatic Mixed Precision (AMP FP16) and gradient clipping with a maximum norm threshold of 1.0.

The complete architectural pipeline of the proposed Vision-Language system is illustrated in Fig. \ref{fig:architecture}. The model consists of four integrated components: the visual patch encoder, the projection bridge, the custom Transformer decoder, and the weight-tied language prediction head.

\subsection{Visual Encoder Backbone}
The visual encoder utilizes the Vision Transformer ViT-B/16 architecture pre-trained on ImageNet-21k (\texttt{google/vit-base-patch16-224-in21k}) \cite{dosovitskiy2020image}. An input image $I \in \mathbb{R}^{H \times W \times C}$ ($224 \times 224 \times 3$) is partitioned into a sequence of non-overlapping $16 \times 16$ spatial patches $x_p \in \mathbb{R}^{N \times (P^2 \cdot C)}$, where $P = 16$ and the number of patches is:
\begin{equation}
N = \frac{H \cdot W}{P^2} = \frac{224 \cdot 224}{16 \cdot 16} = 196
\end{equation}
Each flattened patch is linearly projected into a 768-dimensional latent space. A learnable classification token $[CLS]$ is prepended to the sequence, and 1D learnable position embeddings $E_{\text{pos}} \in \mathbb{R}^{197 \times 768}$ are added element-wise:
\begin{equation}
z_0 = [x_{\text{class}}; x_p^1 E; \dots; x_p^N E] + E_{\text{pos}}
\end{equation}
The sequence passes through 12 Transformer encoder blocks, each consisting of Multi-Head Self-Attention (12 heads, $d_k = 64$) and Multi-Layer Perceptron (MLP) blocks ($d_{\text{ff}} = 3072$). In our primary configuration, the ViT backbone parameters ($\approx 86\text{M}$) remain frozen to preserve pre-trained general visual semantics and accelerate training.

\subsection{Projection Bridge}
To decouple the encoder representations from the decoder and facilitate gradient conditioning, the 197 visual token representations are projected through a linear bridge layer followed by Layer Normalization:
\begin{equation}
Z_{\text{memory}} = \text{LayerNorm}(z_{12} W_{\text{proj}} + b_{\text{proj}})
\end{equation}
where $W_{\text{proj}} \in \mathbb{R}^{768 \times 768}$. The resulting tensor $Z_{\text{memory}} \in \mathbb{R}^{B \times 197 \times 768}$ serves as the immutable visual key and value representations for all decoder cross-attention layers.

\subsection{Custom Pre-LN Transformer Decoder}
The text generation decoder is constructed from scratch without relying on canned recurrent abstractions. It consists of a stack of $L = 6$ identical Transformer decoder layers operating with model dimensionality $d_{\text{model}} = 768$, $h = 8$ attention heads, and inner feed-forward dimension $d_{\text{ff}} = 2048$.

We implement the Pre-LayerNorm (pre-LN) formulation, which places normalization layers inside the residual branches prior to attention and feed-forward operations. Pre-LN significantly improves gradient stability compared to post-LN designs, eliminating the need for delicate learning rate warmup schedules in deep decoders. Each decoder layer executes three sub-operations:
\begin{enumerate}
    \item \textbf{Masked Multi-Head Self-Attention:} Computes causal self-attention across text tokens. An upper-triangular mask $M \in \mathbb{R}^{T \times T}$ ($M_{ij} = -\infty$ for $j > i$) prevents query tokens from attending to subsequent tokens:
    \begin{equation}
    \text{SelfAttn}(Q, K, V) = \text{softmax}\left(\frac{Q K^T}{\sqrt{d_k}} + M\right) V
    \end{equation}
    \item \textbf{Multi-Head Cross-Attention:} Queries $Q_t \in \mathbb{R}^{T \times 768}$ derived from text representations attend to keys $K_v \in \mathbb{R}^{197 \times 768}$ and values $V_v \in \mathbb{R}^{197 \times 768}$ from the visual encoder memory:
    \begin{equation}
    A = \text{softmax}\left(\frac{Q_t K_v^T}{\sqrt{d_k}}\right), \quad \text{CrossAttn} = A \cdot V_v
    \end{equation}
    Crucially, our custom implementation directly returns the cross-attention probability tensor $A \in \mathbb{R}^{B \times h \times T \times 197}$, allowing external extraction of spatial heatmaps without modifying PyTorch internals.
    \item \textbf{Position-wise Feed-Forward Network:} A two-layer MLP with Gaussian Error Linear Unit (GELU) activation:
    \begin{equation}
    \text{FFN}(x) = \text{GELU}(x W_1 + b_1) W_2 + b_2
    \end{equation}
\end{enumerate}

\subsection{Weight Tying and Prediction Head}
Following token embedding projection, the decoder output states $H_T \in \mathbb{R}^{B \times T \times 768}$ are normalized and mapped to vocabulary logits. We implement weight tying between the input token embedding matrix $E_{\text{tok}} \in \mathbb{R}^{30522 \times 768}$ and the final classification projection layer:
\begin{equation}
\text{Logits}_t = H_t E_{\text{tok}}^T + b_{\text{out}}
\end{equation}
Weight tying reduces total trainable parameters by $\approx 23.4\text{M}$ parameters (from 94.7M to 71.33M) and significantly reduces vocabulary overfitting.

The Up-Down and $M^2$ models achieve higher CIDEr by employing heavy Faster R-CNN region proposal networks and reinforcement learning fine-tuning (SCST), which are orthogonal to our pure sequence-to-sequence attention objective. Noticeably, our model demonstrates exceptionally high METEOR scores ($\approx 0.490$ vs. $0.277$), primarily attributable to the WordPiece subword tokenizer which maps morphological variants to common roots.

\section{Observations}
\subsection{Key Strengths and Novelty}
\begin{enumerate}
    \item \textbf{Pure Attention Decoupling:} The architecture dispenses with recurrent units entirely, achieving parallelized training speeds of 11.1 ms per sample during inference.
    \item \textbf{Native Attention Accessibility:} Unlike existing frameworks that monkey-patch PyTorch internals, our decoder directly returns cross-attention matrices during generation.
    \item \textbf{Robust Regularization:} The combination of weight tying, label smoothing (0.1), and AMP prevents overfitting on the 118k image training split.
\end{enumerate}

\subsection{Limitations}
\begin{enumerate}
    \item \textbf{Frozen Visual Encoder:} Freezing ViT-B/16 prevents fine-grained visual adaptation to domain-specific COCO objects.
    \item \textbf{Standard Maximum Likelihood Training:} The model is trained purely with cross-entropy teacher forcing, without reinforcement learning (SCST) optimization directly on CIDEr.
\end{enumerate}

\section{Conclusion and Future Work}
\subsection{Conclusion}
In this project, we designed, implemented, and empirically evaluated a Vision-Language image captioning system utilizing a Vision Transformer (ViT-B/16) visual encoder and a custom six-layer Transformer language decoder built from scratch. Evaluated on the benchmark MS COCO 2017 dataset, the architecture demonstrates strong convergence, dropping validation perplexity to 9.73 and achieving a competitive CIDEr score of 1.0385 and BLEU-4 of 0.3225 with beam search ($k=3$). The model exhibits explainable visual grounding through native cross-attention extraction, validating the efficacy of the all-attention paradigm for vision-language tasks.

\subsection{Future Work}
Promising directions for future exploration include:
\begin{enumerate}
    \item Partial fine-tuning of the final 2 ViT encoder blocks to adapt visual features directly to descriptive captioning tasks.
    \item Implementing Self-Critical Sequence Training (SCST) using CIDEr as the reward signal to align token generation with consensus metrics.
    \item Exploring larger visual foundation backbones, such as CLIP ViT-L/14, to capture richer multimodal semantic alignments.
\end{enumerate}
